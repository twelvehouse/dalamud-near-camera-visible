# Near Camera Visible

A Dalamud plugin for FFXIV that stops your character and mount from vanishing when the camera is
close while mounted.

While you are mounted, the game hides your character and mount once the camera gets too close.
This plugin turns that off so they stay visible up close, which is handy for close-up screenshots.
First-person view is left as is.

## Installation

Add the custom repository URL in Dalamud's Plugin Installer settings, then install Near Camera Visible
from the list.

```
https://raw.githubusercontent.com/twelvehouse/DalamudPlugins/main/pluginmaster.json
```

## Usage

- Enabled by default.
- `/nearcam` toggles it on and off.
